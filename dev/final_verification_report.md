## Reproducible final evidence workflow

Prepared command, to run only when root allocates the rendering GPU:

```sh
python -m scripts.finalize_verification --review-agents --out dev/final_verification.json
```

The new script validates all ledger source hashes and the four locked core
hashes, pins the existing FrozenMission, and selects the latest accepted source.
It compares the rerun to the newest earlier accepted version with a different
source hash, never to its own historical score. It performs actual locked
optimization and holdout evaluation; holdout diagnostics are explicitly false.
The JSON includes only whitelisted measured per-seed/aggregate metrics, with no
holdout autopsy. All mission clauses are checked against the fresh aggregates.
STOP_DONE requires the fixed contract, every mission clause, both aggregate
success flags and unchanged source/ledger evidence. It never appends an entry
or promotes rerun results.

With `--review-agents`, the actual configured Crusoe architect and both
specialists consume their saved latest guidance through the bounded per-agent
memory lifecycle. Valid static proposals are saved only under timestamped
`dev/agent_review_drafts/` as **unverified**, followed by accepted-source
verification. Drafts are never executed, promoted or copied over the accepted
controller. Fresh version/hash/context receipts are included in the report.
A missing client produces an explicit failure report rather than simulated
agent activity.

Local preparation validation: the module's `--help` argument parsing completed
successfully. No GPU, actual model calls or physics evaluation were started by
this preparation task. The final JSON is generated by the real run; it is not
prepopulated with the historical log values above.
